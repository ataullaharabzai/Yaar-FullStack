Registration page 
- Form should not be empty.
- Password must be at least 8 char.
- Create account button navigates to home page after validation true.
- Phone number should be a Number.
- Phone number should not be less than 9 or more than 10.
- Only +93 country code is allow.


Login page
- Phone field should not be empty.
- Only +93 code number is allow.
- Phone number should be a Number.
- Phone number should not be less than 9 or more than 10.
- Continue as guest navigates to home page.
- Create account button navigates to home page after validation true.


OTP page
- OTP boxes should not be empty.
- OTP boxes should not be incomplete.
- 3344 is valid OTP code otherwise invalid OTP code.
- Verify button redirects to home page after correct OTP code.


Add address page
- Navigate to Login page while clicking on logout button.
